# Проект "Lesson001"

## 📌 Описание
Этот проект содержит базовые примеры работы с Python. Он включает скрипты для вывода сообщений в консоль и демонстрации базового синтаксиса языка.

## 🚀 Как запустить

### Установка Python
Перед запуском убедитесь, что у вас установлен Python 3. Вы можете проверить версию командой:
```bash
python --version
```

### Запуск скриптов
Чтобы выполнить основной файл, запустите команду:
```bash
python main.py
```
Аналогично можно запустить `test.py`:
```bash
python test.py
```

## 📂 Структура проекта
- `main.py` – основной скрипт, выводящий "Hello World"
- `test.py` – демонстрационный скрипт с тестовыми строками
- `README.md` – этот файл с описанием проекта
- `LICENSE` – MIT лицензия на использование кода
- `HELP.md` – (можно использовать для инструкций)
- `img/` – изображения (если нужны для проекта)
